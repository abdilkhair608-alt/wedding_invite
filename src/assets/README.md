# Aset ilustrasi pernikahan

Dibuat menggunakan built-in imagegen pada sesi desain proyek ini. Hasil PNG
dikonversi menjadi JPEG untuk mengurangi ukuran file tanpa mengubah komposisi.
Setiap gambar berukuran 1536 × 1024. Tidak ada foto orang, dan gambar tidak
dimaksudkan sebagai dokumentasi mempelai atau lokasi acara sebenarnya.
